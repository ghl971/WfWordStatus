# Warframe 实时看板

> Warframe 游戏状态一站式监控面板，实时展示开放世界轮换、虚空裂缝、突击任务、午夜电波等信息。

![主题](https://img.shields.io/badge/主题-深色_/_浅色-blueviolet)

## 📋 功能

| 模块 | 说明 |
|------|------|
| **开放世界** | 夜灵平野、奥布山谷、魔胎之境、双衍王境的昼夜 / 冷热 / 毒化 / 情绪周期 |
| **虚空裂缝** | 所有活跃裂缝列表，含纪元、节点、阵营、剩余时间；中断任务高亮 |
| **突击** | 当日突击的三个阶段，含关卡、等级、限制条件与剩余时间 |
| **每日任务** | 钢铁防线、异变、集团任务及声望进度 |
| **仲裁 · 无尽回廊** | 当前仲裁节点、维特鲁斯精华奖励、回廊模式与周常奖励进度 |
| **Baro Ki'Teer** | 虚空商人抵达倒计时、当前售卖物品及杜卡德价格 |
| **钢铁之路** | 每日 / 每周献祭、侵袭倍率、Teshin 商品、荣誉等级 |
| **虚空风暴 · 午夜电波** | 虚空风暴节点、电波等级、每日 / 每周 / 精英挑战进度 |
| **警报** | 进行中的特殊警报与奖励 |
| **赏金任务** | 各开放世界的赏金信息（阶段、等级、声望、奖励池） |
| **入侵** | 活跃入侵及进度条、阵营对抗、剩余时间 |
| **活动 & 新闻** | 最新游戏动态、Darvo 特卖、开发者直播资讯 |

## 🚀 使用

直接打开 `index.html` 即可使用，无需构建步骤或后端服务。

```
index.html
```

页面每 5 分钟自动刷新（`<meta http-equiv="refresh" content="300">`），所有倒计时实时更新。

## 🎨 主题切换

点击右上角主题按钮可在 **深色模式** 与 **浅色模式** 间切换，偏好设置保存在本地。

## 🧩 技术栈

- 纯 HTML + CSS + JavaScript，零依赖
- CSS 变量驱动主题系统，支持深色 / 浅色双主题
- SVG 图标内联，无外部资源请求（除 Google Fonts）
- 响应式布局：适配桌面（3 列）、平板（2 列）、手机（1 列）
- 玻璃拟态卡片设计（`backdrop-filter`）
- 倒计时系统：实时更新所有定时器，低于 5 分钟红色预警、低于 15 分钟黄色提醒
